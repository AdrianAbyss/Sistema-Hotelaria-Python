# Sistema de Hotelaria

Aplicação de linha de comando em Python para gerenciar quartos, clientes e reservas de um hotel.

## Funcionalidades

- Cadastro e listagem de quartos e clientes
- Check-in e check-out
- Relatório de reservas
- Armazenamento local dos dados em `dados_em_json.json`

## Como executar

Requer Python 3.10 ou superior. No terminal, execute:

```bash
python trabalho.py
```

O arquivo `dados_em_json.json` é criado automaticamente ao salvar os primeiros dados.
